# Reference

This section holds lookup material — content you consult for one specific fact (a parameter
name, a default value, a property, a return type) rather than read from start to end. It
complements the [Guides](../guides/index.md), which explain *how* and *why* to use a feature
with worked examples; here you look up exactly *what* a cmdlet accepts, or *what* an object
you already have in hand actually contains.

This reference is split into two parts: the cmdlets themselves, and the PowerShell types they
return.

<div class="grid cards" markdown>

-   **Cmdlets**

    ---

    Syntax, parameters, defaults, and usage examples for every public cmdlet — generated from
    the same comment-based help `Get-Help -Full` shows you directly in the console, organized
    here by category for browsing.

    [:octicons-arrow-right-24: Cmdlets](../cmdlets/index.md)

-   **Types**

    ---

    Property and method tables for the PowerShell classes PSScriptBuilder's cmdlets return —
    build results, source locations, coverage data, dependency graphs, and more. Useful when
    you already have an object in a variable and want to know exactly what it contains,
    without switching back to a guide for the full explanation.

    [:octicons-arrow-right-24: Types](types.md)

</div>
