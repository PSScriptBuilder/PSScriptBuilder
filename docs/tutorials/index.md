# Tutorials

Tutorials walk you through complete, end-to-end scenarios, each starting from a defined
situation and ending with a working result. They are independent of each other, not a course to
work through in sequence — pick the one that matches where you are today.

Two of them are alternative starting points depending on whether a PSScriptBuilder project
exists yet: start from [Building Your First Project](building-your-first-project.md) with
nothing in place, or from [Migrating to PSScriptBuilder](migrating-to-psscriptbuilder.md) if
your code already exists as a single file or as separate files without a build system.
[Setting Up Release Management](setting-up-release-management.md) builds on top of either one —
it assumes a working PSScriptBuilder project is already in place.

If you are looking for an explanation of one specific feature rather than a full scenario, see
the [Guides](../guides/index.md) instead.
