# Getting Started

Getting Started gets PSScriptBuilder installed and a first script built end to end, with just
enough explanation at each step to keep things moving. Work through it in order: install the
module first, then scaffold a project and run your first build. From a clean machine to a
working, dependency-ordered script takes only a handful of commands and requires nothing beyond
PowerShell 5.1 or later — no external dependencies, and the same steps work on Windows, Linux,
and macOS.

This section favors speed over explanation. For the same journey with a full walkthrough of
*why* each step works the way it does and what happens under the hood, see
[Building Your First Project](../tutorials/building-your-first-project.md) in the Tutorials
section instead.
